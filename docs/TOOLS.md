# Desk tools

Generated by scripts/gen_tools_doc.py from each tool's --schema; do not edit by hand.

Every tool prints one JSON envelope with `--json` and describes it with `--schema` (no network, no desk file). The envelope keys every tool shares, besides `tool`, `tool_version` and its own `payload`:

- `delay_min`: `"integer minutes | null"`
- `generated_at`: `"ISO-8601 UTC"`
- `mode`: `"read-only"`
- `schema_version`: `1`
- `source`: `"string | null"`
- `status`: `"ok | quiet | error | usage | fired | unavailable"`

The error envelope (status `error`, `usage` or `unavailable`), besides `tool` and `tool_version`:

- `error`: `{"code": "string (for example invalid_arguments, source_unavailable, python_too_old)", "message": "string"}`
- `generated_at`: `"ISO-8601 UTC"`
- `mode`: `"read-only"`
- `schema_version`: `1`
- `status`: `"error | usage | unavailable"`

One exit-code table for every tool:

| Exit code | Meaning |
| --- | --- |
| 0 | quiet: ran, nothing to post (informational output at most) |
| 1 | error: the tool failed (bug, unreadable file, bad data) |
| 2 | usage: invalid arguments |
| 10 | fired: a rule fired or a signal stands; the message must be posted |
| 20 | unavailable: an input the verdict needs is missing or stale; say UNAVAILABLE, never HOLD |
