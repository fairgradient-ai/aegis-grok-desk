# README graphics

The five SVG files in `assets/` are generated by [build_graphics.py](build_graphics.py). Edit the script, not the SVG
files, then rebuild.

| File | Shown in the README |
| --- | --- |
| [hero.svg](../hero.svg) | the header picture (wide screens) |
| [hero-mobile.svg](../hero-mobile.svg) | the header picture (screens up to 600 px wide) |
| [desk-flow.svg](../desk-flow.svg) | how the desk works, under "Meet the desk" (wide screens) |
| [desk-flow-mobile.svg](../desk-flow-mobile.svg) | how the desk works (screens up to 600 px wide) |
| [demo-card.svg](../demo-card.svg) | the output of `opening_bell.py --demo`, under "Try it now" |

The README shows the first four through HTML `<picture>` tags, which the repository's link gate does not check; the
links above are what it checks, and `tests/gates/test_readme_assets.py` fails when a picture is missing, out of step
with this script, or below 4.5:1 text contrast.

## Rebuild

From the repository root:

```
python3 assets/src/build_graphics.py
```

It writes `hero.svg`, `hero-mobile.svg`, `desk-flow.svg`, `desk-flow-mobile.svg` and `demo-card.svg` into `assets/`,
and prints each file's size. To check that the committed files match a fresh render without writing anything:

```
python3 assets/src/build_graphics.py --check
```

`demo-card.svg` is the exact output of `python3 scripts/opening_bell.py --demo`. The script runs that command from this
checkout when it builds the card, so rebuild after any change to the tool's text. The demo reads the synthetic fixture
desk and writes nothing. Long lines are wrapped at word boundaries, and the unwrapped text is repeated in the card's
description.

## Rules the script keeps

- Standard-library Python only (Python 3.9 or later). No fonttools, no image libraries, no downloads.
- No embedded fonts: text uses the reader's `system-ui` and monospace font stacks, so every line is kept well inside
  its box.
- Each file is well-formed XML, has `role="img"`, a `<title>` and a `<desc>`, and stays under 60 KB. The script
  checks this and refuses to write a file that fails.
- Each graphic is a dark card with its own background, so it reads on light and dark pages. Every text colour reaches
  at least 4.5:1 contrast on it.
- Any animation is CSS only and stops when the reader asks for reduced motion.
- The artwork is original to Aegis Desk. It uses no third-party art, logo or font. Text on the cards comes from the
  desk's own tools and fixture desk; no number is made up.
