# scripts/

Standard-library Python only, written to the Python 3.9 syntax floor. Tools print their own
output and nothing else; the repository gates stop at the first failing step. Run everything from
the repository root.

## Repository gates

| File | Purpose |
| --- | --- |
| `check.sh` | The whole gate: structure (agents, skills, links, emoji, script mentions, version pins), the Python 3.9 floor, the three sub-gates below, the unit-test suite with its count floor, the command journeys, the `docs/TOOLS.md` drift check (step 9, `gen_tools_doc.py --check`) and the role-skill drift check (step 10, `gen_role_skills.py --check`). Takes an optional repository root (`bash scripts/check.sh [root]`) so the fixture trees under `tests/fixtures/gates/` are gated with the real scripts. |
| `check_manifests.py` | One version across `plugin.json` and every mirrored manifest, tag-pinned marketplace refs, hooks declared once per runtime, no `skills`, `agents` or `commands` keys in the manifests Claude Code and Grok Build read, the desk-rule paragraph mirrored in `AGENTS.md` and `GEMINI.md`, the routine manifest's schema line. |
| `check_no_write_paths.py` | The AST no-write gate: network modules only in the market-data client and GET-only there (every request is a direct `urllib.request.Request(...)` with the literal `GET` and no body; no subclass of `Request`, no change of a built request's verb, body or target, no reflection into third-party HTTP clients); write-capable and dynamic-execution standard-library modules nowhere; `subprocess` only in the listed gates and `tests/gates/`; a prose scanner over skills, agents, docs, rules, template, routines and the root instruction files, with `no_write_allowlist.txt` for documented counter-examples. |
| `check_grok_template.py` | The Grok Bot template contract in `template/grok-bot.json`: release pin, skill hashes, publication status, and a byte comparison against the release tag once the tag exists. |
| `cli_journeys.py` | Runs the published commands as subprocesses in a scrubbed environment and screens their output for order-shaped text. The gate journeys run against any tree; the tool journeys run only against this checkout, each on a temporary copy of a fixture desk (`tests/fixtures/desk/`, or `tests/fixtures/desk_recon/` for the settlement branches) with `--offline --now <instant>`, so nothing under `tests/` is ever written. A journey with `steps` runs a chain of commands on one copy (the snapshot one command writes feeds the next) and checks every command's exit code and JSON keys. |
| `gen_tools_doc.py` | Generates `docs/TOOLS.md` from every desk tool's `--schema` and parser (sorted, no clock, no terminal width, identical on 3.9-3.13); `--check` fails on drift or on a tool missing from its list. |
| `gen_role_skills.py` | Generates one `skills/aegis-role-<seat>/` skill per agent from its System prompt, and the role-skill index blocks in `skills/README.md` and `SETUP.md`; `--check` fails on drift and refuses (never deletes) an orphaned role skill. |
| `release_bump.py` | The first change after a release is tagged: `python3 scripts/release_bump.py <next> [--check]` moves the version in `plugin.json`, every mirrored manifest, the marketplace refs, the template's release and skill hashes, every pin `check.sh` step 4 checks, the role skills and the tool versions in `docs/TOOLS.md`, and writes every file or none. `--check` lists the changes and writes nothing. It refuses a version that is not plain `X.Y.Z`, not greater than the current one or already tagged (it reads the tags from `.git` as files, and refuses when it cannot read them), never edits `CHANGELOG.md` or `docs/RELEASE.md`, and lists plain mentions of the old version for a person to review. A maintainer script, not a desk tool. |
| `no_write_allowlist.txt` | Exact paths or globs whose prose may contain a documented write-looking counter-example; an entry that matches nothing fails as stale. |
| `test_count_floor.txt` | The minimum number of tests the suite must discover. Raised in every pull request that adds tests, never lowered, never left at zero. |

## Library (`aegis_desk/`)

| Module | Purpose |
| --- | --- |
| `bsm.py` | Generalised Black-Scholes-Merton price and natural-unit Greeks on `math.erfc`, ported from the Aegis quant engine with its golden values. |
| `iv.py` | Bracketed Brent implied-volatility solver with arbitrage bounds and explicit statuses (`ok`, `expired`, `below_intrinsic`, `above_bound`, `no_root`). |
| `greeks.py` | Desk-unit Greeks (theta per calendar day, vega per volatility point, rho per rate point), absolute-delta helper and position scaling. |
| `units.py` | The desk's constants: 365-day year, seconds per year, volatility and rate points, contract multiplier. |
| `market_clock.py` | NYSE sessions, the embedded 2026-2027 holiday and early-close table with its source and expiry date, America/New_York daylight-saving rules without `tzdata`, days to the last trading day, exercise cutoffs, vendor clock reconciliation. |
| `occ.py` | OCC option-symbol parsing and rendering (canonical, compact and `O:`-prefixed forms). |
| `_vendor/toml_reader.py` | Strict TOML 1.0 reader (`Decimal` numbers, finite only, no `eval`) used on every interpreter; `toml_compat.py` cross-checks it against `tomllib` where that exists. |
| `state.py` | File lock, atomic writes, fsync'd JSONL appends and quarantine of corrupt state files. |
| `contract.py` | The shared command-line contract: `--json`, `--schema`, `--timeout`, `--desk-root`, `--offline`, `--now` (one UTC spelling, `YYYY-MM-DDTHH:MM:SSZ`, parsed identically on every interpreter), the exit-code table (0 quiet, 1 error, 2 usage, 10 fired, 20 unavailable) and the JSON envelope. |
| `version.py` | The release version read from `plugin.json` (`0.0.0` when it is missing or unreadable). |
| `market_types.py` | Frozen vendor types (`Quote`, `Bar`, `SessionWindow`, `CalendarDay`, `ClockInfo`, `RequestReceipt`) built from the recorded Tradier shapes; a present-but-garbled field raises `MarketTypesError` instead of becoming a quiet `None`. |
| `desk_paths.py` | The desk root's layout (`desk.toml`, `positions.csv`, `state/`, `data/cache/`, `data/book/`, `journal/`, `levels/`, ...) and `ensure_runtime_dirs`, the only function that creates desk directories. |
| `desk_config.py` | Strict reader for the owner-authored `desk.toml` (sections `desk`, `owner`, `market_data`, `rates`, `levels`; `machine_role` rejected anywhere) with the file's sha256 and the freshness bound `feed_delay_min + quote_ttl_min + grace_min`. |
| `tradier_client.py` | The only network module: GET-only Tradier market-data client over an explicit `urllib` opener (pinned sandbox or production host, allow-listed paths, literal `GET`, no body, no redirects, no proxy, TLS 1.2 or later), token from the environment variable or a mode-0600 file, one receipt per request, credential redaction in every message and refusal of a `200` that echoes the credential; `OfflineTransport` serves the recorded fixture sets. |
| `quote_cache.py` | Quote and chain cache under `data/cache/` with the desk-wide 60-per-minute request ledger, per-run request caps, a run-wide stop after a quota or credential error, and the production-host refusal; `open_market_data` is the entry point the tools share. `get_history` serves daily bars from `data/cache/history/` or the vendor; a range that ended before the last closed session is a record and is served from the cache without a time-to-live. |
| `quote_qc.py` | Quote quality: session-aware freshness per side (`regular`, after the close, before the open, closed days), spread grades A-F on the printed two-decimal spread, liquidation and mid marks, `usable_for_rules`. The tools `quote_cache.py` and `quote_qc.py` classify the session with `research/calendar.toml`'s full closures, as the book tools do; a calendar that does not parse is exit 1 `calendar_invalid`. |
| `positions_csv.py` | The hand-edited `positions.csv` as the book of record: the Aegis import columns plus the desk extensions (`trade_id`, `opened`, `open_price_per_share`, `status`, `closed`, `closed_quantity`, `close_price_per_unit`, `underlying_stop`, `note` tags), the money conventions (signed cash flows, `cost_basis_total` required on option rows, both forms reconciled when present), `Decimal` everywhere, physical row numbers and the file's sha256. A file-level error fails the file; a row-level error quarantines the row's `trade_id` group. `parse_positions_bytes` parses bytes a caller already read, so a snapshot and the rows describe one byte string. |
| `grouping.py` | Groups the rows by `trade_id` into strategies (covered call, cash-secured put, protective put, collar, the four verticals, long and short options and stock, custom) with each group's basis, net cost, open and closed legs, stock coverage and the account and underlying consistency checks that quarantine a group. |
| `calendar_events.py` | Strict reader for the owner-sourced `research/calendar.toml`: earnings and ex-dividend entries with status, amount, source and `checked_utc` (unknown is never zero), `dividend_yield`, AM-settled roots and their settlement values, full and early closures; the freshness lint behind `calendar_check.py`. `extra_closures()` is the full-closure mapping the market clock takes as extra holidays. |
| `payoff.py` | Expiration payoff per leg and per group and the closed-form metrics of each structure (max profit, max loss, breakevens, unbounded tails) in total money on a `Decimal` grid; the closed forms are asserted equal to the grid to the cent, and a breakeven is reported only when it is positive. |
| `pnl.py` | Signed-cash-flow P/L on the mid and liquidation bases: unrealized on the open quantity against the remaining cost basis, realized per row from `close_price_per_unit` and the pro-rata closed basis, day P/L against the desk's own previous snapshot, cost to close, percent captured, realized today / month-to-date / year-to-date. `Decimal` only; no `float`. |
| `book.py` | The book: positions, groups, one batched quotes request, quality grades, IV and Greeks per leg, group metrics, portfolio totals as sums over the groups with usable marks (every excluded group named; `net_delta` only when every open group has Greeks), concentration against the declared equity, data quality. `load_book` is the one entry point from an open `MarketData` to the book dict, `write_snapshot` the end-of-day record under `data/book/` and `write_report` the `reports/book.md` rendering; the session is classified with the calendar's full closures, as in every desk tool that reads a desk root (`market_clock.py` reads no desk file and uses the embedded NYSE table alone). Each leg carries its fresh sides (`fresh_bid`, `fresh_ask`: the liquidation sides of a grade A-E quote, null for grade F; a zero ask stays 0, which is no offer and not a price to close at) and `extrinsic_bid`, computed as in the assignment watch: the fresh bid less the intrinsic value at the usable underlying mid, null unless both quotes are stamped within 60 s of each other. `mark_source` is `mid` only when the grade is A-D with both sides fresh, so a consumer gates P/L and loss readings on `mark_source`, never on the grade. |
| `recon.py` | Reconciliation of the CSV with what the market did: settlement of open legs past their last trading day from the official close (`EXPIRED_OTM`, `PROBABLE_ASSIGNED`, `PROBABLE_EXERCISED`, `PIN_UNCERTAIN`, `CASH_SETTLED`, `SETTLEMENT_PENDING`, `SETTLEMENT_UNKNOWN`, `EXPIRED_UNRECORDED`), proposed CSV edits re-rendered from the owner's own cells, coverage and roll-link checks, `ACTED_UNCHANGED`, quote-missing findings, the plausibility check behind `positions_check.py` and the `data/positions/` snapshot. It never writes `positions.csv`. |
| `expiry.py` | The expiry sheet: every open option leg's last trading day and settlement type, the act-by instant from the owner's broker cutoff (the earlier of the cutoff and the close on an early-close day), the dividend tier of short calls (bid-side extrinsic against the dividend, listed only when the last cum-dividend day falls within the contract's life), the pin tier on the last and next-to-last trading days, the between-the-strikes check for verticals and the implication of assignment or exercise for the group. |
| `heartbeat.py` | Heartbeat records per routine under `state/heartbeat/` (schema 1: run instant, exit code, status, lateness against the scheduled ET slot, message hash) and the append-only history. |
| `exit_rules.py` | The exit rulebook: the strict grammar with every parameter bounded in its safe direction, the metric catalogue read from the book's fields (take-profit on the fresh, conservative side; loss and every other role only on a leg whose `mark_source` is `mid`; a short leg's zero ask is no offer), Kleene three-valued evaluation, the verdict precedence EXIT_SIGNAL > UNAVAILABLE > WATCH > HOLD (HOLD is never reported while an applicable rule is unavailable), data gaps (`unavailable`) kept apart from a missing previous snapshot (`no_history`), the suppression tags, the adoption lint (one take-profit metric per held structure, no loss rule on a covered call's short leg), the per-rule and file sha, and `book_from_json` for saved books. |
| `rule_state.py` | The per-(group, rule) state machine behind the rules: armed, pending, fired, cooldown; time-based confirmations on the quote's own stamps; re-arm next trading day, immediately or on a hysteresis retreat, bounded to one trading day; a cooldown that holds a re-arm back after a post but never past the next session's open; first observation; carry-forward on adoption keyed by the per-rule sha; the state file written atomically under the desk lock. |
| `alerts.py` | The exact text of every message: EXIT SIGNAL, WATCH, UNAVAILABLE banners, HOLD notices, CONFIG CHANGED, the rulebook digest, the pre-close and watch-alive lines, each ending with the fixed footer; every number comes from one formatter per kind and is recorded in the message's emitted document. |
| `alert_lint.py` | The proof a message may be posted: every numeric token (attached forms included) equals a string the desk emitted, every identifier, sha, version, date and clock was printed by the desk, the footer is present and exact, and no trade, order or advice language appears (the forbidden-phrase table, imperative sentence starts, split and homoglyph forms). |
| `signals.py` | The signal and alert journals (`journal/signals.jsonl`, `journal/alerts.jsonl`, the day's Markdown journal), signal ids `SIG-YYYYMMDD-NNN`, the open signals with their ack state and the re-post ladder; a torn journal line is skipped and reported, never a reason to hide the rest. |
| `levels.py` | Threshold levels: every adopted rule of every open group as an option or spread price, an underlying level, a band or a date, with its arithmetic shown; rounding on the class's tick grid (standard unless `desk.toml [levels]` names a penny class) in the direction that keeps a resting take-profit inside the rule's firing region and a loss alert no later than the rule; take-profit levels marked resting-eligible against the fresh side, loss levels alert-only; model levels (delta) by root-finding with IV and date fixed, labelled estimates; no order shape. |
| `routines.py` | The routine manifest model (`routines/manifest.toml`): its structural rules (slots, the 08:00-10:00 ET delay window, chains of the eight step tools, dependencies with a 20-minute gap, posting policies), the weekly budget per cadence profile, the Grok Bot Auto-review texts of `routines/autoreview.toml`, and the day audit of the heartbeat history (expected, ran, late, missed). |
| `doctor.py` | The desk doctor's checks: release pin (a clean checkout at the tag), interpreter and standard-library modules, holiday-table expiry, token source, sandbox verification (one GET of the sandbox clock; a 401 means not a sandbox token), machine role, broker-looking environment-variable names (names only), desk files, market status and timezone offset, connector readback age, heartbeats, and the engine selftest. |
| `summaries.py` | The Morning Desk Sheet and the EOD Desk Brief: one linted message each, composed only from the desk's own records (the reconciliation and docket records, last night's levels, the doctor's result, the book snapshot, the signal journals, the routine audit, the incident files), with a stale or missing upstream record printed as UNAVAILABLE and nothing summed; the brief carries the P/L of every open trade from the snapshot. |
| `structuring_config.py` | Strict reader for the owner-authored `structuring.toml`: the acknowledged disclosure, the general knobs and the `covered_call`, `roll`, `protective_put` and `collar` sections (windows in calendar days, bands, minimums, the earnings and ex-dividend policies and one declared objective each), every section required, unknown keys refused, with the file's sha256. |
| `approval.py` | The approval-level check, the first reader of `desk.toml`'s self-attested `approval_level`: the desk's level convention (0 to 5), the level every step of a plan needs on the account's holdings in the safe order, the exposure the other order would leave, and the refusal line when a step needs more than the owner's level. |
| `structuring.py` | The Aegis Structuring Desk's engine for one group of `positions.csv`: the group's own quotes, expirations and in-window monthly chains through `quote_cache`, every leg priced (European Black-Scholes-Merton, labelled), the candidates of a roll analysis or of a covered call, protective put or collar proposal labelled against `structuring.toml` and ranked by its declared objective with fixed tie-breaks, one best candidate only when one passes every criterion, the after-state, and the replacement a ROLL ticket names. |
| `structuring_text.py` | The exact text of roll analyses and proposals: every number through one writer, the fixed lines, the structuring footer and the strict lint in structuring mode (a text that fails becomes the WITHHELD line), the `journal/structuring.jsonl` record and the report files. |
| `tickets.py` | Tickets for one group: the legs of CLOSE, UNWIND_STOCK, LET_ASSIGN, MONETIZE_PUT or ROLL in the safe order in the fixed leg grammar, the approval-level check over every step, each leg's quote, the cash at the conservative side and at the mid, the realized estimate, and for ROLL the replacement's criteria labels and after-state. |

## Desk tools

Every tool takes `--json`, `--schema`, `--timeout`, `--desk-root`, `--offline` (fixture sets under the
desk root's `fixtures/tradier/`) and `--now`, and exits by the one table: 0 quiet or ok, 1 error,
2 usage, 10 fired, 20 unavailable. None of them writes outside the desk root, and none of them
reaches a broker: the only network path is the GET-only market-data client.

| Tool | Purpose |
| --- | --- |
| `market_clock.py` | The NYSE session at an instant (`--at`), the next trading day, the previous close and, with `--expiry`, the settlement day, last trading day, calendar and trading days to expiry and the exchange exercise cutoff. Reads and writes nothing. |
| `quote_cache.py` | Serves quotes (and one chain with `--chain SYMBOL --expiration YYYY-MM-DD`) from the cache or the vendor, within the 60-per-minute budget; exit 20 when a symbol is missing, the host is production or no token is configured. |
| `quote_qc.py` | Grades the served quotes (freshness, spread, marks) and says whether each is usable for rules; exit 20 when any symbol is stale or missing, and on every closed day (weekend, holiday or a calendar closure), cached copy or not. |
| `heartbeat.py` | Writes one routine's heartbeat (`--routine`, `--exit-code` or `--status`, `--scheduled-et`, `--message-file`) or lists them with `--list`. |
| `positions_check.py` | Validates `positions.csv` (a file-level error is exit 1 with `error.code` `positions_invalid`; a row-level error quarantines its group), prints the strategy groups and checks each entry price against the current mark for an order-of-magnitude mistake; exit 20 when a group is quarantined or a leg could not be checked, 0 when CLEAN. Reads only. |
| `csv_recon.py` | The reconciliation: snapshots `positions.csv` under `data/positions/` (the file's one read), settles every open leg past its last trading day from the vendor's daily bars, runs the coverage, roll-link, acknowledgement and quote checks and, with `--diff`, prints the proposed CSV lines (never applied: the file is the owner's). Exit 0 CLEAN, 10 EDITS_PENDING, 20 UNAVAILABLE (a pin, an unknown settlement, an unrecorded expiry, a quarantined group or an unmatched symbol), 1 ERRORS. |
| `book.py` | Marks the book from one quotes request and prints the group, leg and portfolio lines; `--snapshot` writes `data/book/<ET date>.json`, the record that gives the next day's day P/L, and `--report` writes `reports/book.md`, both whatever the exit code (an UNAVAILABLE book is still the record of what was known). Exit 20 when an open group is unavailable or quarantined. |
| `calendar_check.py` | The freshness lint of `research/calendar.toml` against the held symbols (`STALE` beyond `--max-age-days`, default 7; `MISSING`; `UNKNOWN_DIVIDEND` under a short call; `PAST`); no market data, nothing written; exit 20 on any finding or when the calendar is missing. |
| `assignment_watch.py` | Grades the dividend and pin tiers of the open option legs and prints their act-by instants; exit 10 when a tier fired (`HIGH`, `PIN HIGH`, in the money on the last trading day, a vertical between its strikes on a due leg), 20 when a listed leg or a group could not be graded, 0 when quiet. |
| `expiry_checklist.py` | `--week` the docket of contracts due this week, `--tomorrow` the T-1 preview, `--final-call` the expiry-day sheet with act-by times from the owner's broker cutoff; exit 10 when contracts are listed, 20 when a listed leg or a group could not be graded, 0 when nothing is due. |
| `exit_check.py` | Evaluates the adopted rulebook (or a candidate with `--rules PATH --dry-run`) against the book built now or a saved book (`--book PATH`) and prints one verdict per group with every fired, pending, cooldown, unavailable and no-history rule, then the portfolio and underlying sections; reads the rule state and never writes it. Exit 10 on an EXIT_SIGNAL, 20 on an UNAVAILABLE group. |
| `rules_diff.py` | What a candidate rulebook (`--candidate PATH`) would change against the adopted one on one book (built now, `--book PATH` or the newest snapshot with `--latest-snapshot`), each with a scratch rule state; exit 10 when a group verdict changes. |
| `rules_adopt.py` | The owner-tapped adoption of one rulebook version (`--file`, `--version`, `--owner-phrase "adopt rules X.Y.Z"`): strict parse, the adoption lint against the held structures, refusal inside regular trading hours unless `--allow-rth`, an immutable `rules/exit_rules-X.Y.Z.toml`, an atomic `rules/ADOPTED`, the append-only `rules/CHANGELOG.md` and the rule state carried forward; nothing is written on any refusal. |
| `book_check.py` | The routine check: quotes, the book, the adopted rules, the state transitions and the posting rules (transitions only, CONFIG CHANGED first, the rulebook digest, the re-post ladder for an unacknowledged EXIT SIGNAL, a standing UNAVAILABLE re-posted until acknowledged, the HOLD notice once), every part linted before it is printed (a part that fails is withheld and named). Without `--post` it is a dry run that writes no desk record; `--summary` adds the pre-close line, `--watch-alive` the watch-alive line. Exit 10 on an EXIT SIGNAL, 20 on an UNAVAILABLE group, 1 when the composed message fails the lint. |
| `ack.py` | The owner's acknowledgements in `state/acks.jsonl`: `list` and `show` the open signals with their ladder position, `ack` a signal, and the owner-tapped `snooze`, `acted` and `config` (`--owner-tapped` required; routines never run them). Reads no quote and never touches the CSV, `desk.toml`, the rulebook or the journals. |
| `alert_lint.py` | Lints a message file against an emitted document (`--emitted-file`; `--footer rules`, `snapshot` or `structuring`, else the document's own footer key): exit 0 when it passes, 1 with every finding (line and column) when it does not. |
| `trigger_levels.py` | Writes the threshold-level sheet `levels/<ET date>.md` and `.json` from the book built now or the end-of-day snapshot (`--from-snapshot`), and with `--plan GROUP` the exit-plan card `plans/<GROUP>.md`; never writes rule state; exit 20 when a group is unavailable. |
| `routine.py` | The single reviewed routine entry point: `routine.py <id> [--slot HH:MM]` refuses to run any step unless the checkout is the pinned release (exit 20; `--allow-dirty` for development, announced in the message and logged), runs the manifest chain in-process, applies the routine's posting policy, lints each part and the whole message (a failing part is withheld), and writes the heartbeat, journal and run record. |
| `routine_audit.py` | Prints the weekly run budget per cadence profile (`--budget`), the three Auto-review texts (`--rules-text`) and the day audit of the heartbeats (expected, ran, late, missed); posts nothing. |
| `eod_summary.py` | The Morning Desk Sheet (default) or the EOD Desk Brief (`--brief`) from the desk's records; exit 20 when any record is missing or late, never 10. |
| `desk_doctor.py` | Twelve checks, one PASS or FAIL verdict (`--quick` for the pre-open subset, `--selftest` for the engine goldens); writes `state/doctor.json`; exit 20 on FAIL. |
| `desk_init.py` | Renders `desk.toml` once, byte for byte, from the owner's interview answers (`--answers PATH.json`), records an owner-entered ex-dividend intake in `research/calendar.toml` and renders `structuring.toml` from the structuring interview's answers (validated by its reader before any write); refuses to replace any of them without `--replace --owner-tapped`. |
| `opening_bell.py` | One symbol's quote, the nearest standard expiration at least 20 days out, the ATM implied volatility and the move it implies, from three market-data requests; ends with the market-snapshot footer (it is not a signal). |
| `exit_ticket.py` | The Aegis Structuring Desk's ticket for one group of `positions.csv`, only when the owner asks: `--trade AG-YYYYMMDD-NN --action` CLOSE, UNWIND_STOCK, LET_ASSIGN, MONETIZE_PUT or ROLL (ROLL with `--new-expiration` and `--new-strike`); the legs in the safe order in the fixed leg grammar with each leg's bid, ask, mid and quote grade, the approval-level check, the cash at the conservative side and at the mid, the realized estimate, and for ROLL the replacement's criteria labels and after-state; the owner supplies the limit. Writes `tickets/` only on a TICKET and one `journal/structuring.jsonl` record per printed text. Exit 0 TICKET or NOT_APPLICABLE, 20 UNAVAILABLE or REFUSED, never 10. |
| `roll_analysis.py` | On the owner's request only, never a routine step: the replacement candidates for the short call of a covered call group (`--trade AG-...`), priced from that underlying's own chains, labelled against `structuring.toml` and ranked by its objective; names one best candidate when one passes every criterion; exit 0 BEST, NONE_QUALIFIES or NOT_APPLICABLE, 20 UNAVAILABLE, REFUSED, `criteria_missing` or `config_unacknowledged`; writes `reports/rolls/` only for BEST and NONE_QUALIFIES (a complete evaluation; NOT_APPLICABLE writes no report) and one `journal/structuring.jsonl` record per printed text. |
| `propose.py` | On the owner's request only, never a routine step: a covered call, protective put or collar (`--structure`) on a group that holds shares only (`--trade AG-...`), labelled against `structuring.toml` and ranked by its objective; never a new symbol, a spread, an uncovered short or a cash-secured put; exit 0 BEST, NONE_QUALIFIES, NOTHING_TO_PROPOSE or NOT_APPLICABLE, 20 UNAVAILABLE, REFUSED, `criteria_missing` or `config_unacknowledged`; writes `reports/proposals/` only for BEST and NONE_QUALIFIES (a complete evaluation; NOT_APPLICABLE and NOTHING_TO_PROPOSE write no report) and one `journal/structuring.jsonl` record per printed text. |
